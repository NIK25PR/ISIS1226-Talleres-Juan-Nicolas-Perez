# Taller 6 - GUIs con Swing y Java2D

## Cómo ejecutar
1. En Eclipse: File > Import > Existing Projects into Workspace y seleccionar esta carpeta.
2. Abrir `src/uniandes/dpoo/swing/interfaz/principal/VentanaPrincipal.java`.
3. Click derecho > Run As > Java Application.

La aplicación se debe ejecutar con la raíz del proyecto como directorio de trabajo
(es lo que hace Eclipse por defecto), porque las imágenes se cargan desde `./imagenes/`.

## Uso
- **Nuevo**: abre una ventana para crear un restaurante. Se hace click en el mapa para marcar su ubicación.
- **Ver todos**: abre el mapa con todos los restaurantes (verde = visitado, rojo = no visitado).
  Con los botones "Todos" / "Visitados" se filtra lo que se muestra.
